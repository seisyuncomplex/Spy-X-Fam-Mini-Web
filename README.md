# Spy x Family Shortcut Page (Mini Website) 🥜

Welcome to my very first website! 

This is a simple, static shortcut page dedicated to the anime/manga series *Spy x Family*. I built it entirely from scratch using **HTML** and **CSS**. 

## 🛠️ Project Details & History
* **Built:** February 2024 
* **Note:** This website was created *before* Season 3 of the anime was released.
* **Development:** No AI tools were used. All HTML and CSS were written manually as a learning project.
* **Purpose:** A simple navigation hub to quickly access information about the characters and the series.

## ✨ Features
* **6 Navigation Tabs:** Home (SpyxFam), Anya, Loid, Yor, Bond, and S3 Info.
* **Wiki Shortcuts:** Clicking a tab opens the respective page, which contains an underlined link to direct you straight to the character's official Wiki Fandom page.
* **S3 Info Page:** A dedicated page to display information regarding Season 3.
* **Custom Styling:** Styled using a single external CSS file (`style`).

## 📁 File Structure
Here is a quick breakdown of the files included in this repository:
* `index` - The homepage (SpyxFam)
* `anya`, `loid`, `yor`, `bond` - Character pages linking to their respective Wiki Fandom pages
* `s3info` - Information page regarding Season 3
* `style` - The CSS stylesheet that styles the entire website
* `*.jpg` - The image files used across the website (e.g., `anya.jpg`, `bond.jpg`, `spyxfam.jpg`)
